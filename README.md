# Glorp Battle

Прототип боевой системы в духе Mega Man Battle Network: правила боя опираются на MMBN6, а текущий вертикальный срез проверяет собственный набор боевых чипов и физику поля. Спецификация: [docs/GDD.md](docs/GDD.md).

**Играть:** https://zavtraleto.github.io/glorp-battle/ (отладка: добавьте `?debug=1`).

Сборка публикуется автоматически при каждом пуше в `main` (GitHub Actions: тесты → сборка → GitHub Pages, см. `.github/workflows/deploy-pages.yml`).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер (доступен в локальной сети для теста с телефона) |
| `npm test` | тесты (Vitest) |
| `npm run typecheck` | проверка типов |
| `npm run build` | проверка типов + сборка в `dist/` |

## Как играть

Игра управляется через физический терминал NET-01 ([docs/TERMINAL.md](docs/TERMINAL.md)): бой и меню — на экране-кинескопе, всё остальное — органы терминала.

На экране названия два пункта. **Play** — линейный забег из 6 боёв подряд, каждый бой — 2–3 волны врагов; шаги 5 и 6 — элитные, финальный этап собирается случайно по сиду забега. Забег начинается со стартовой папки из 8 чипов (Cannon ×3, Sword ×2, AreaGrab ×2, Guard ×1, GDD §6.3), и за забег она не меняется. HP переносится между боями и волнами, автоматического лечения нет. Смерть или отказ от забега (ABANDON в паузе) — экран GAME OVER и возврат к названию. Пауза — клавиша ❚❚ слева внизу пульта, Esc или сворачивание вкладки. Пункт меню выбирается трекболом (тап — выбрать) или касанием пункта на экране. **Tutorial** (GDD §10.5) — один бой из четырёх волн, по уроку на волну: шаг и выстрел, заряд из двух чипов, захват ряда и меч, экзамен без подсказок; умереть в нём нельзя, а после `TUTORIAL CLEAR` — назад к названию.

Урон наносят только чипы; когда очередь добора пустеет, использованные чипы перемешиваются и возвращаются в неё. В вертикальном срезе ровно 10 чипов: Cannon, Sword, Area Grab, Mine, Block, Break, AirShot, Spreader, WideSword и Guard. Они позволяют захватывать панели, ставить мину и блок, временно ломать клетку, отталкивать врагов и поглощать попадание.

## Управление

- **NAVIGATION (трекбол):** каждый штрих по шару — ровно один шаг; не отрывая палец, можно сделать второй рывок, остановиться и свайпнуть снова или повернуть на 90°. Неподвижный палец шаги не повторяет. Тап по шару — выстрелить первый чип очереди атаки. Мышью — перетаскивание и клик по шару.
- **Ряд чипов:** рука из 5 кассет. Касание кассеты ставит её в очередь атаки (любые чипы, до 5), повторное касание снимает её до запуска. Каждый тап по Attack запускает ровно один следующий чип; между ними можно свободно двигаться. Заряд из 2–5 чипов открывает Combo State без ограничения времени: игрок остаётся на обычной скорости, а враги и их эффекты замедляются до последнего чипа или Combo Break. Реальная потеря HP сжигает неиспользованный хвост; Guard и другие полностью предотвращённые попадания комбо не ломают. Cooldown следующей руки начинается после завершения Combo State.
- **Клавиатура:** WASD / стрелки — шаг (удержание — повтор); 1–5 — выбрать чип в слоте; Space или F — чип; Esc — пауза. В меню: стрелки и Enter.
- **DBG** (справа внизу): отладочная панель и оверлей. Пауза — клавиша слева внизу.
- Лучше открывать в Chrome или добавить на домашний экран: встроенные браузеры мессенджеров (Telegram) могут закрываться жестом смахивания.

## Отладка

- В dev-режиме панель и оверлей включены сразу; в сборке — кнопкой DBG, через `?debug=1` или клавишей `` ` `` / `F2`.
- Параметры URL: `?debug=1&seed=123&battle=3&encounter=e1&wave=2&tutorial=2&folder=all&god=1&timescale=0.5`. `battle=N` (1–4) или `encounter=<id>` (этапы забега `s1`…`s5`, отладочные `n1`…`n6`, `e1`, `e2`) пропускает экран названия и сразу открывает бой со стартовой папкой; `folder=all` — вместо неё по одному каждого чипа; `wave=N` — начать с N-й волны; `tutorial=N` — туториал с урока N. Терминал: `?hitzones=1` (зоны нажатия), `?rscale=400`, `?crtres=240x320`, `?bench=1` (замер кадра).
- В dev-режиме в консоли доступен `window.__glorp` (world, session, input, loop, sceneRenderer/battleView, terminal, perf, tuning, cheats, startBattle).
- Debug → Cheats: бессмертие, ИИ врагов вкл/выкл, убить всех, принудительная атака, выдать любой чип в очередь, HP игрока, перезапуск боя.
- Debug → Field: состояние любой клетки (BROKEN / EMPTY / OBJECT), демо всех состояний, новый облик врагов.
- Debug → Session: бой 1–4, сид, шаг забега.
- Debug → Session → folder: `starter` или `all` (перезагружает страницу, то же что `?folder=…`).
- Все параметры из `src/config/tuning.ts` меняются в панели (Tuning) и сохраняются в `localStorage`; «reset to defaults» сбрасывает.
