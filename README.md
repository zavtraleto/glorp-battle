# Glorp Battle

Прототип боевой системы в духе Mega Man Battle Network: правила боя — по MMBN6, чипы и вирусы — по MMBN3. Спецификация: [docs/GDD.md](docs/GDD.md).

**Играть:** https://zavtraleto.github.io/glorp-battle/ (отладка: добавьте `?debug=1`).

Сборка публикуется автоматически при каждом пуше в `main` (GitHub Actions: тесты → сборка → GitHub Pages, см. `.github/workflows/deploy-pages.yml`).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер (доступен в локальной сети для теста с телефона) |
| `npm test` | тесты (Vitest) |
| `npm run typecheck` | проверка типов |
| `npm run build` | проверка типов + сборка в `dist/` |

## Как играть

Игра управляется через физический терминал NET-01 ([docs/TERMINAL.md](docs/TERMINAL.md)): бой и меню — на экране-кинескопе, всё остальное — органы терминала.

На экране названия три старта — три папки по 30 чипов: **Basic** (пушки, мечи, бомбы), **Field** (средний уровень, чипы поля) и **Random** (собирается случайно по правилам, GDD §6.3). Дальше — линейный забег из 10 боёв подряд: элитные бои на шагах 5 и 8, на шаге 10 — босс Monolith. HP переносится между боями и полностью восстанавливается после побед на шагах 3, 6 и 9. Папка за забег не меняется. Смерть или отказ от забега (ABANDON в паузе) — экран GAME OVER и возврат к названию. Пауза — клавиша ❚❚ на верхней рамке, Esc или сворачивание вкладки. Пункт меню выбирается трекболом (тап — выбрать) или касанием пункта на экране.

Урон наносят только чипы; когда очередь добора пустеет, использованные чипы перемешиваются и возвращаются в неё. Поле меняется: панели трескаются, проваливаются, их можно захватить и перегородить камнем. Чипов 27 (в том числе меняющие поле: Geddon, AreaGrab, PanlGrab, PanlOut, Repair, RockCube), вирусов 8 и босс, уровни 1–3.

## Управление

- **NAVIGATION (трекбол):** рывок по шару — ровно один шаг, палец можно не отрывать: остановись или смени направление, и следующий рывок даст ещё шаг; тап по шару — выстрелить первый чип очереди атаки. Мышью — перетаскивание и клик по шару.
- **Ряд чипов:** рука из 5 кассет. Касание кассеты ставит её в очередь атаки (совместимые — одно имя или один код), повторное касание снимает её до первого выстрела. После 3 использованных чипов рука пополняется (Refresh) без остановки боя.
- **Клавиатура:** WASD / стрелки — шаг (удержание — повтор); 1–5 — выбрать чип в слоте; Space или F — чип; Esc — пауза. В меню: стрелки и Enter.
- **DBG** (справа внизу): отладочная панель и оверлей. Пауза — клавиша слева внизу.
- Лучше открывать в Chrome или добавить на домашний экран: встроенные браузеры мессенджеров (Telegram) могут закрываться жестом смахивания.

## Отладка

- В dev-режиме панель и оверлей включены сразу; в сборке — кнопкой DBG, через `?debug=1` или клавишей `` ` `` / `F2`.
- Параметры URL: `?debug=1&seed=123&battle=3&encounter=e1&folder=field&god=1&timescale=0.5`. `battle=N` (1–4) или `encounter=<id>` (`n1`…`n14`, `e1`…`e4`, `boss`) пропускает экран названия и сразу открывает бой; `folder=basic|field|all` — папка для такого боя (`all` — по одному каждого чипа). Терминал: `?hitzones=1` (зоны нажатия), `?rscale=400`, `?crtres=240x320`, `?bench=1` (замер кадра).
- В dev-режиме в консоли доступен `window.__glorp` (world, session, input, loop, sceneRenderer/battleView, terminal, perf, tuning, cheats, startBattle).
- Debug → Cheats: бессмертие, ИИ врагов вкл/выкл, убить всех, принудительная атака, сдвинуть счётчик Refresh, выдать любой чип в очередь, HP игрока, перезапуск боя.
- Debug → Field: состояние любой клетки (BROKEN / EMPTY / OBJECT), демо всех состояний, новый облик врагов.
- Debug → Session: бой 1–4, сид, шаг забега.
- Debug → Session → folder: папка `basic`, `field` или `all` (перезагружает страницу, то же что `?folder=…`).
- Все параметры из `src/config/tuning.ts` меняются в панели (Tuning) и сохраняются в `localStorage`; «reset to defaults» сбрасывает.
