# Glorp Battle

Прототип боевой системы в духе Mega Man Battle Network 1. Спецификация: [docs/GDD.md](docs/GDD.md).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер (доступен в локальной сети для теста с телефона) |
| `npm test` | тесты (Vitest) |
| `npm run typecheck` | проверка типов |
| `npm run build` | проверка типов + сборка в `dist/` |

## Управление

- Телефон: свайп в любом месте экрана (кроме кнопок) — шаг; удержание пальца после свайпа — повтор шага.
- Кнопка BUSTER: нажатие — выстрел, удержание — заряд (кольцо: зелёное — ур. 1, розовое — ур. 2).
- Кастом-экран открывается сам в начале боя; дальше — кнопкой CUSTOM или нажатием на шкалу, когда она заполнена. На экране: нажатие на чип — выбрать, на последний выбранный или CANCEL — отменить, ADD — пропустить ход и расширить руку, OK — в бой.
- Десктоп: перетаскивание мышью — как свайп; WASD / стрелки — шаг, удержание — повтор; Space — Buster (удержание — заряд); Q/E — кастом-экран (на нём: стрелки/WASD — курсор, Enter/Space — выбрать, Backspace — отмена, Tab — к OK).

## Отладка

- В dev-режиме панель и оверлей включены всегда; в сборке — через `?debug=1`, клавишу `` ` `` / `F2` или тройной тап в левом верхнем углу (по HP).
- Параметры URL: `?debug=1&seed=123&battle=3&folder=p1&god=1&timescale=0.5`.
- В dev-режиме в консоли доступен `window.__glorp` (world, input, loop, sceneRenderer, tuning, cheats, startBattle).
- Debug → Cheats: бессмертие, ИИ врагов вкл/выкл, убить всех, принудительная атака, заполнить шкалу, открыть кастом-экран, HP игрока, перезапуск боя.
- Debug → Session → folder: папка `mvp` или `p1` (перезагружает страницу, то же что `?folder=p1`).
- Все параметры из `src/config/tuning.ts` меняются в панели (Tuning) и сохраняются в `localStorage`; «reset to defaults» сбрасывает.
