# Glorp Battle

Прототип боевой системы в духе Mega Man Battle Network 1. Спецификация: [docs/GDD.md](docs/GDD.md).

**Играть:** https://zavtraleto.github.io/glorp-battle/ (отладка: добавьте `?debug=1`).

Сборка публикуется автоматически при каждом пуше в `main` (GitHub Actions: тесты → сборка → GitHub Pages, см. `.github/workflows/deploy-pages.yml`).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер (доступен в локальной сети для теста с телефона) |
| `npm test` | тесты (Vitest) |
| `npm run typecheck` | проверка типов |
| `npm run build` | проверка типов + сборка в `dist/` |

## Как играть

Игра управляется через физический терминал NET-01 ([docs/TERMINAL.md](docs/TERMINAL.md)): бой и меню — на экране-кинескопе, всё остальное — органы терминала.

Экран названия (с номером поколения) → **START** → забег из 10 шагов: на каждом шаге выбор из 2–3 боёв (обычный или элитный), в конце — босс Monolith. HP переносится между боями, лечат только чипы Recover. После победы на лотке выезжают три кассеты-награды: OK забирает выбранную, SKIP пропускает. После смерти игрок оставляет один чип своей папки следующему поколению — он появится в стартовой папке следующего забега с меткой `Gnn`. Пауза — клавиша ❚❚ на верхней рамке, Esc или сворачивание вкладки; в паузе можно сдаться (ABANDON). Пункт меню выбирается трекболом и EXECUTE или касанием пункта на экране.

В бою игрок раз в секунду сам стреляет из Buster по своей колонке. Поле меняется: панели трескаются, проваливаются, их можно захватить и перегородить камнем. Чипов 27 (в том числе меняющие поле: Crack, Geddon, Steal, Repair, RockCube), вирусов 9 с уровнями 1–3.

## Управление

- **NAVIGATION (трекбол):** жест по шару — ровно один шаг. Мышью — перетаскивание по шару.
- **EXECUTE:** использовать следующий чип (он светится в ряду и вылетает). Без чипов кнопка «глухая». В меню — выбрать пункт.
- **CHIP SELECT:** кастом-экран, когда кольцо светодиодов вокруг кнопки заполнено. В начале боя открывается сам.
- **Лоток (кастом-экран и награда):** касание чипа — в первое свободное гнездо; перетаскивание — в конкретное гнездо; касание или вытягивание чипа из ряда — вернуть; OK — в бой; ADD — пропустить ход и расширить руку.
- **Клавиатура:** WASD / стрелки — шаг (удержание — повтор); Space или F — чип; Q/E — кастом-экран; Esc — пауза. На лотке: стрелки — выбор, Space — взять, Backspace — убрать последний, Enter — OK, R — ADD. В меню: стрелки и Enter.
- **DBG** (слева внизу): отладочная панель и оверлей.
- Лучше открывать в Chrome или добавить на домашний экран: встроенные браузеры мессенджеров (Telegram) могут закрываться жестом смахивания.

## Отладка

- В dev-режиме панель и оверлей включены сразу; в сборке — кнопкой DBG, через `?debug=1` или клавишей `` ` `` / `F2`.
- Параметры URL: `?debug=1&seed=123&battle=3&encounter=e1&folder=p2&god=1&timescale=0.5`. `battle=N` (1–4) или `encounter=<id>` (`n1`…`n14`, `e1`…`e5`, `boss`) пропускает экран названия и сразу открывает бой; `folder=p2` — папка с новыми чипами. Терминал: `?hitzones=1` (зоны нажатия), `?rscale=400`, `?crtres=240x320`, `?bench=1` (замер кадра).
- В dev-режиме в консоли доступен `window.__glorp` (world, session, input, loop, sceneRenderer/battleView, terminal, perf, tuning, cheats, startBattle).
- Debug → Cheats: бессмертие, ИИ врагов вкл/выкл, убить всех, принудительная атака, заполнить шкалу, открыть кастом-экран, выдать любой чип в очередь, HP игрока, перезапуск боя.
- Debug → Field: состояние любой клетки (BROKEN / EMPTY / OBJECT), демо всех состояний, новый облик врагов.
- Debug → Session: шаг забега, номер поколения, очистка наследия.
- Debug → Session → folder: папка `mvp` или `p1` (перезагружает страницу, то же что `?folder=p1`).
- Все параметры из `src/config/tuning.ts` меняются в панели (Tuning) и сохраняются в `localStorage`; «reset to defaults» сбрасывает.
