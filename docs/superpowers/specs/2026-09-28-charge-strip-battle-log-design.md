# Полоска заряда, battle log и пауза на CRT (2026-09-28)

## Проблема

На плейтесте игрокам не хватало двух вещей: видеть текущий выбранный заряд и подсказки, что можно выбрать ещё чип. Сейчас заряд показывает только текст 14-сегментного дисплея над CRT (`LINE HIT 4 + ____ + ____`, GDD §7.2). Во время боя глаз смотрит на поле и этот текст не читает.

## Решение: три части, порядок работ 1 → 3 → 2

### 1. Полоска заряда на CRT

- Место: нижний край картинки, под полем, справа от HP игрока. Иконки идут слева направо в порядке выстрела.
- Иконки монохромные, на HUD-холсте CRT (`terminal/crt/crtCanvas.ts`). Модель полоски собирает `terminal.ts` из `chips.attack`, `world.activeChip`, `world.combo`, `chips.phase`. Сим не меняется.
- Состояния:

| Момент | Полоска |
|---|---|
| Заряд пуст, фаза `selecting` | `?` (дышит) |
| Выбрано 1–2 | иконки + `?` |
| Выбрано 3 и больше | только иконки: подсказка кончается на `hand.QUEUE_CELLS` = 3, но 4-й и 5-й чипы выбрать можно (GDD §7.2) |
| Первый Attack, заряд 2+ (Combo State, GDD §6.6) | `?` нет, в конце `✓` |
| Одиночный чип запущен | иконка горит, пока идёт action; `✓` нет |
| Идёт цепочка | текущий чип жёлтый (жёлтый = действие), выпущенные гаснут |
| Combo Break | хвост мигает красным и исчезает |

- Цвет: выбранные — фосфорный, текущий — жёлтый, Combo Break — красный.
- `?` и `✓` — пиксельные значки полоски, а не символы шрифта.
- **Источник иконки — одна функция** `chipMask(id)`: маска w×h с уровнями яркости `0` (прозрачно), `1`, `2`. Сейчас маска строится из `chipIcons.ts`: `k` становится прозрачным, остальные цвета по яркости делятся на 2 уровня. Потом тот же интерфейс сможет строить маску из PNG: декодировать один раз при загрузке, яркость квантовать до 2 уровней, прозрачность брать из альфы, масштаб только nearest. Отрисовка при этом не меняется. PNG лучше делать в 1–2 тона и примерно 16×16.
- HUD перерисовывается по ключу `hudKey`: состояние полоски входит в ключ.

### 2. Battle log на пульте

- 14-сегментный дисплей переезжает с полосы над CRT на пульт, в область слева от трекбола, на всю высоту пульта. Он лежит в плоскости пульта (`controlMount`) и наклоняется вместе с ним (`CONTROL_TILT`).
- Шрифт мельче, примерно 5–6 строк по 12–14 символов (подбирается под iPhone 13/16, Pro Max, 16:9 и ПК).
- **Новая строка появляется сверху**, старые уезжают вниз и тускнеют; нижняя, самая старая, пропадает.
- Строки (тексты черновые, все из `i18n/en.ts`, у каждого символа есть глиф 14-сегментного шрифта):

| Событие | Строка |
|---|---|
| Чип добавлен в заряд | `+ LINE HIT 4` |
| Чип запущен | `> LINE HIT 4` |
| Урон врагу | `METTIK -40` |
| Враг убит | `METTIK DOWN` |
| Урон игроку | `YOU -10` |
| Комбо началось / завершено / сорвано | `COMBO x3` / `COMBO OK` / `COMBO BREAK` |
| Волна началась / зачищена | `WAVE 2` / `WAVE CLEAR` |

- В лог не пишутся снятие чипа, движение, панели, барьеры и перетасовка папки.
- Источник строк — `SimEvent`, которые `main.ts` разбирает каждый тик. Для выбора чипа сим события не шлёт: эту строку лог берёт из изменения заряда (рост `chips.attack` в фазе `selecting`), а не добавляет событие в сим. Если это окажется хрупким, заведём событие `chipQueued`.
- Модель лога чистая (без DOM): строки, их возраст и яркость. Лог очищается в начале каждого боя.
- Полосы `LAYOUT_DISPLAY` над CRT больше нет, её высоту забирает CRT.

### 3. Пауза на CRT

- Физическая клавиша паузы на пульте удаляется (`deckControls.ts`, зона `pause` в `layout.ts`).
- Пауза становится значком `II` в левом верхнем углу картинки CRT, частью HUD, виден только в бою.
- Зона нажатия не меньше 56 CSS px, проверяется раньше зоны `screen` (свайп по бою). Срабатывает на `pointerdown` (немедленный отклик). Если свайп начнётся ровно в этом углу, он поставит паузу; для маленького угла это приемлемо.
- Esc и автопауза работают как раньше.

- В `CLAUDE.md` и `AGENTS.md`: «the pause key sits bottom-left on the control panel» → пауза в левом верхнем углу CRT.

## Тесты

- Модель полоски: `?` / `✓` / лимит в 3 слота / одиночный чип / Combo Break.
- `chipMask`: маска для каждого чипа есть, уровни только 0–2.
- Модель лога: событие → строка, новая строка сверху, лимит строк, затухание, очистка в начале боя.
- Компоновка: зона паузы внутри CRT и раньше `screen`; лог слева от трекбола и не пересекает кольцо.
- 14-сегментный шрифт: глифы для всех строк лога (как тест пиксельного шрифта).
